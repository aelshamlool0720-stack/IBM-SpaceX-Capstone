# Original course notebooks

These six Jupyter notebooks are organized in the order of the **IBM Applied Data Science Capstone** workflow. The notebook files themselves are preserved **byte-for-byte** from the repository's earlier version; only the paths and filenames have been changed. They remain course exercises rather than separate independent products.

| Step | Notebook | Main purpose | Previous filename |
|---|---|---|---|
| 01 | [API data collection](01_api_data_collection.ipynb) | Obtain and normalize historical launch records using the SpaceX API | `jupyter-labs-spacex-data-collection-api-v2 (1).ipynb` |
| 02 | [Wikipedia web scraping](02_wikipedia_web_scraping.ipynb) | Extract historic launch-table data from Wikipedia | `jupyter-labs-webscraping (1).ipynb` |
| 03 | [Exploratory analysis](03_exploratory_data_analysis.ipynb) | Analyze launch outcomes, payloads, sites, orbits, and trends | `jupyter-labs-eda-dataviz-v2 (1).ipynb` |
| 04 | [SQL exploration](04_sql_exploration.ipynb) | Use SQL to explore launch-site and mission records | `jupyter-labs-eda-sql-coursera_sqllite (1).ipynb` |
| 05 | [Launch-site mapping](05_launch_site_mapping.ipynb) | Visualize geographic launch-pad locations with Folium | `lab-jupyter-launch-site-location-v2 (1).ipynb` |
| 06 | [ML classification](06_machine_learning_classification.ipynb) | Build and evaluate launch-landing classifiers | `SpaceX-Machine-Learning-Prediction-Part-5-v1 (2).ipynb` |

Some files include the original IBM/SKills Network instructions, installation commands, placeholder sections, or cells without saved output. They have not been silently rewritten or represented as a fully independent implementation.

**For reproducible, concise results**, start with [the separate model-comparison script](../analysis/reproduce_results.py) or [the documented evaluation](../analysis/RESULTS.md). Use the interactive application in [`dashboard/`](../dashboard/) to view the historical Dash sample.

Run notebook installation commands selectively; older course cells may target outdated environments. Notebook-local CSV files or SQLite databases generated by exercises should not be mistaken for the separate dashboard dataset.
