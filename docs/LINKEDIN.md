I completed my IBM Data Science Professional Certificate capstone: **SpaceX Falcon 9 Landing Prediction**.

The problem: can historical launch information help classify whether a Falcon 9 first-stage booster lands successfully?

The project covers data collection through the SpaceX API and web scraping, preparation and SQL analysis, visualization with Folium and Plotly Dash, and four classical ML classifiers.

In a reproduced evaluation of IBM's historical 90-launch sample, logistic regression and SVM each scored **83.3% accuracy on 18 held-out flights**. However, logistic regression predicted successful recovery for **3 of 6 actual failures**. This is why I also report confusion matrices and limitations instead of accuracy alone.

The repository includes the course notebooks, reproducible analysis script, model evaluation summary and dashboard source.

GitHub: https://github.com/aelshamlool0720-stack/IBM-SpaceX-Capstone

*This is a course-based educational case study using historical IBM datasets, not a live SpaceX system.*
